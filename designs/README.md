# Design Explorations

These five static directions are intentionally content-free. They are not a final brand system and do not represent approved copy, project claims, or final information architecture.

## Directions

1. **Signal / graphite + safety orange** — editorial technical portfolio with strong left alignment and evidence rails.
2. **Field Notes / bone + oxide red** — research-forward, paper-like, tactile but restrained.
3. **Night Console / near-black + electric mint** — instrument-like, dense, operational, suited to runtime and security work.
4. **Blue Hour / slate + cobalt** — calm systems engineering, structured project index and detail pane.
5. **Archive / warm white + ink + brass** — publication and artifact emphasis, strongest for the paper/research layer.

Open `index.html` directly in a browser. Each direction includes a homepage composition, project index, detail-page anatomy, and a contact/footer treatment represented with neutral blocks rather than content.
