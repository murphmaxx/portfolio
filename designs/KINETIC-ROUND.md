# Kinetic directions

A second design round inspired by the reference's high-energy, full-screen, image-led personal-site behavior. This is an original portfolio direction, not a reproduction of the reference site.

Open `kinetic.html` locally to review five mockups:

- Apex — lime / black
- Redline — paper / red
- Night Drive — ultraviolet / ink
- Paddock — oxide / cream
- Telemetry — steel / yellow

21st.dev research informed the interaction candidates:

- Quordix Work Hero — full-viewport hero, magnetic type, orbit rings, scroll fade
- Immersive Scroll Gallery — scaling image narrative
- Interactive Video Portfolio Scroller — synchronized text and video track
- Stacking Cards / Scroll Cards — scroll-driven project stack
- Infinite Moving Cards / Marquee — horizontal project or technology rails

The 21st.dev source code is not copied into this static archive. It will be adapted only after the visual direction is selected and the production stack is chosen.
