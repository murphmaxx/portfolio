# Technical portfolio — visual QA notes

## Current prototype status

The prototype is a structural and visual direction, not a publishable portfolio. Placeholder labels and links remain intentionally visible.

## Independent critique

- The previous campaign direction was rejected by the user as playful, templated, poorly framed, and insufficiently defense/industrial.
- The current direction responds with a technical dossier: carbon/steel surfaces, paper contrast field, oxidized bronze signal, rectangular actions, capability matrix, project records, and a document artifact.
- The remaining risk is that the page may still read as a designed concept rather than a lived defense-industrial system until real project media and evidence replace abstract diagrams.

## Required next verification

- Real browser screenshot at 1280px desktop and a narrow mobile width.
- Keyboard walk through every navigation and action.
- Confirm project rows remain legible with real screenshots and longer factual descriptions.
- Replace abstract system-field geometry with a verified artifact or a restrained technical diagram.
- Evaluate whether the capability matrix is useful to recruiters or should become a simpler “what I build” statement.
- Add real repository links only after public status review.

## Intentional exceptions

- Placeholder content remains because the user requested design and architecture before content.
- Static file uses remote Google Fonts during exploration; production should self-host or choose a stable loading strategy.
- The Impeccable detector is degraded because optional HTML parser modules are unavailable.
