# Apex prototype

The first production-style Apex homepage prototype. Content is intentionally marked as placeholder while the interaction model and visual system are reviewed.

## Prototype features

- Full-screen kinetic hero
- Electric cyan signal palette
- Orbit field and scan grid
- Reduced-motion support
- Manual motion toggle
- Skip link and semantic landmarks
- Sticky project sequence
- Responsive mobile transformation
- SVG/CSS system diagram
- Writing artifact section
- Contact close
